## Configuração remota observada

Pages confirmado com `build_type: workflow`, endereço correto e ambiente `github-pages` permitindo a branch `main`. O ruleset `PROD` está ativo, mas contém **Restrict updates** sem atores permitidos, que bloqueia inclusive merges. O ajuste proposto mantém PR, não exclusão e não force-push, substituindo a restrição geral por **Dev checks** obrigatório.

Actions está habilitado com política `local_only`, incompatível com as actions oficiais fixadas por SHA. A proposta de ajuste é uma lista exata de seis commits, sem permissão geral para actions de terceiros. Alterações administrativas aguardam autorização específica; nenhum bypass da branch protegida é usado.

O conector recusou criar o PR com 403. Após autorização explícita para a autenticação local, o cliente oficial GitHub CLI permitiu abri-lo sem exibir credenciais.
