## Correção na revisão local — fetch nativo

Usuário relatou “Falha de rede” sem requisições no Network. Reproduzido em Chromium: `fetch` armazenado e chamado como método de `DriveStorage` recebia contexto inválido (`Illegal invocation`), antes de enviar a requisição. O transporte padrão agora usa uma função que chama `fetch` diretamente. Teste de navegador com GIS/Drive simulados mantém o fetch nativo e verifica chamadas de identificação e leitura. Nenhum log de token adicionado. Este fix corresponde à versão `0.2.1`; a entrega atual inclui também a revisão seguinte, `0.2.2`. A versão inicial planejada era `0.2.0`. O consentimento real foi posteriormente confirmado pelo funcionamento relatado pelo usuário.

## Revisão do usuário e acesso ao arquivo

Usuário confirmou o resultado do fix de fetch: “Funcionou perfeitamente”. Isso confirma o teste local relatado, sem substituir a homologação em produção. O mesmo ciclo de revisão acrescenta o componente reutilizável `DriveFileLink`, apresentado após leitura/gravação de documento existente e removido ao desconectar ou trocar de conta. O link usa `webViewLink` da API com alternativa pelo ID, abre em nova aba e não torna o arquivo público. Versão de entrega alinhada em `0.2.2`; nenhuma tag criada.
