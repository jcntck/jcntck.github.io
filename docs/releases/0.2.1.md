## Correção na revisão local — fetch nativo

Usuário relatou “Falha de rede” sem requisições no Network. Reproduzido em Chromium: `fetch` armazenado e chamado como método de `DriveStorage` recebia contexto inválido (`Illegal invocation`), antes de enviar a requisição. O transporte padrão agora usa uma função que chama `fetch` diretamente. Teste de navegador com GIS/Drive simulados mantém o fetch nativo e verifica chamadas de identificação e leitura. Nenhum log de token adicionado. Versão patch corrigida para `0.2.1` após o usuário confirmar que esta alteração é um fix. A versão inicial planejada era `0.2.0`. Consentimento real segue pendente.
